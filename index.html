Sistem Monitoring Kualitas Tanah pada Tanaman dengan Komunikasi Data LoRa dan Catu Daya Panel Surya. Dirancang untuk monitoring data kualitas tanah yang mencakup kelembapan dan suhu tanah serta udara yang mendukung pengiriman data jarak jauh nirkabel menggunakan frekuensi radio LoRa dari node transmitter lapangan ke node receiver gateway pusat, dilengkapi isolasi bus dual-SPI demi kestabilan pencatatan data saat koneksi terputus menggunakan microSD serta pipeline analitik data menggunakan InfluxDB, Visualisasi Data Grafana, dan notifikasi alert Telegram.
